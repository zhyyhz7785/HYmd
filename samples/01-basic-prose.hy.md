# HyMD 基础示例

这是一份**纯 prose** 的 HyMD 文档，演示 frontmatter 主题声明与标准 Markdown 语法。

## 特性

- 标题、**粗体**、*斜体*
- [链接](https://example.com)
- GFM 任务列表

- [x] 已完成项
- [ ] 待办项

## GFM 表格（轻量）

| 列 A | 列 B |
| --- | --- |
| 1 | 2 |
| 3 | 4 |

行内公式 $E=mc^2$ 由渲染器决定是否支持。

> 引用块在任意 Markdown 工具中均可正常显示。
