| 导出配置项 | `hymd.export.pandocPath / marpPath / browserPath` | Pandoc / Marp CLI / 浏览器路径 |

**导出数据流**

```
.hy.md + .assets
  → transform（sheet→GFM 表，slide→抽出，layout/calc→摘除）
  → docx：Pandoc + reference-doc（theme 匹配）
  → pptx：有 slide 块 → Marp CLI 每块一份；无 slide → Pandoc pptx 回退
  → pdf：Pandoc standalone HTML → Edge/Chrome headless `--print-to-pdf`（@page mm 边距）
```

输出目录默认：`<文档同级>/<stem>.exports/`（如 `03-slide-mixed.hy.exports/`）。

## 八、常见问题

| 现象 | 处理 |
|---|---|
| 扩展激活失败 `No exports main @hymd/parser` | 在 HYmd 执行 `npm run build:vscode && npm run sync:fork`，重启 HYmd Code |
| sheet 预览空白 | 滚到卡片可见区域（懒加载）；看 DevTools 是否有 CSP/加载错误 |
| 保存后公式丢失 | 确认保存走覆盖层「保存」按钮；检查 JSON 是否写入 `.assets` |
| `npm ci` EBUSY | 暂停百度网盘；删 `hymd-code/remote/node_modules` 重试 |
| `npm run compile` getElectronVersion | 确认 `hymd-code/.npmrc` 含 `target="34.3.2"` 与 `ms_build_id` |
| F5 找不到扩展 | 打开的是 **HYmd** 仓库而非 hymd-code；先 `npm run build:vscode` |
| 排版预览空白 / 构建失败 | 先 `npm run build:vscode`；确认 `dist/media/layout-preview.js` 存在 |
| frontmatter 被改成 `***` | 应已通过 frontmatterGuard 修复；若复现，检查是否在源码视图直接编辑 frontmatter |
| M4 导出失败「未找到 Pandoc」 | 安装 Pandoc 或设置 `hymd.export.pandocPath` |
| M4 PDF 失败「未找到 Edge/Chrome」 | 安装浏览器或设置 `hymd.export.browserPath` |
| Marp pptx 失败 | 确认 `npm install` 后 node_modules 含 `@marp-team/marp-cli`；或设置 `hymd.export.marpPath` |
| slide 预览空白 | 滚到卡片可见区域；DevTools 看 `requestSlideSource` / CSP 错误 |
| 导出目录找不到 | 默认在文档旁 `<stem>.exports/`；如 `samples/03-slide-mixed.hy.exports/` |
